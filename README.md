# Modern Python Calculator

A sleek, modern GUI calculator built with Python's tkinter library featuring contemporary design and smooth interactions.

## Features

- **Basic Operations**: Addition (+), Subtraction (-), Multiplication (×), Division (÷)
- **Special Functions**: 
  - Clear (C) - Reset calculator
  - Plus/Minus (±) - Toggle sign
  - Percentage (%) - Convert to percentage
- **Decimal Support**: Full decimal number support
- **Error Handling**: Division by zero and other error protection
- **Modern Design**: Sleek dark theme with contemporary styling and smooth animations

## How to Run

1. Make sure you have Python installed on your system
2. Run the calculator with:
   ```bash
   python calculator.py
   ```

## Usage

- Click number buttons (0-9) to input numbers
- Use operation buttons (+, -, ×, ÷) to perform calculations
- Press '=' to calculate the result
- Use 'C' to clear the calculator
- Use '±' to toggle between positive and negative numbers
- Use '%' to convert the current number to a percentage
- Use '.' to add decimal points

## Modern Interface

The calculator features a contemporary design:
- **Dark Theme**: Sleek dark background (#1a1a1a) with pure black display
- **Modern Typography**: Segoe UI font for crisp, readable text
- **Smart Color Coding**: 
  - Number buttons: Dark gray (#2d2d2d) with white text
  - Operation buttons: Vibrant orange (#ff9500) with white text
  - Function buttons: Light gray (#a6a6a6) with black text
- **Interactive Effects**: Smooth hover animations and visual feedback
- **Enhanced Display**: Larger, more readable display with number formatting
- **Responsive Layout**: Modern spacing and proportions

## Requirements

- Python 3.x
- tkinter (included with most Python installations)
